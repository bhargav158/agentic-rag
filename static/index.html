Agentic RAG Code Assistant

Ask questions about any public GitHub repository and get answers from the actual code, checked by the agent before you see them.

1. Add a GitHub repository

Why paste a link? The assistant answers from the real code, so it has to download and read your repository first.

2. Ask a question

For example: "Where is authentication handled?", "How does the agent call its tools?", "What happens if an API call fails?" You can also ask follow-ups such as "Where is that called from?" or name a file, such as "Explain server.py".
